# Origin and release boundary

This repository retains inherited Git history so prior authorship, copyright, and license evidence remain auditable. The root `LICENSE` is preserved byte-for-byte from that history.

The current implementation is a modernization effort, not a claim of sole authorship. PastureStack changes include an offline policy compiler, a new metadata and nftables enforcement path, container packaging, validation scripts, documentation, and tests. Historical source remains subject to its original copyright and license terms.

The maintained image is built from the current working tree and the distribution license evidence in this repository. Historical product names and marks remain attribution only and are not used as current product branding.
